# SellToner.com Privacy Notice Webpage

A professional, responsive privacy notice webpage for SellToner.com.

## Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Easy Navigation**: Table of contents with smooth scrolling to sections
- **Professional Styling**: Clean, modern design with good readability
- **Accessibility**: Semantic HTML and proper heading hierarchy
- **Compliance**: Covers GDPR, CCPA/CPRA, and other privacy regulations
- **Print-Friendly**: Optimized for printing

## How to Use

1. Open `index.html` in a web browser
2. Use the sticky header navigation to jump to specific sections
3. Use the table of contents for quick navigation
4. Contact information is provided at the bottom

## Customization

To customize for your needs:

- Update company name and contact details in the content
- Modify colors in `css/style.css` by changing the CSS custom properties (--primary-color, etc.)
- Add or remove sections as needed
- Update the "Last Updated" date when making changes

## Responsive Breakpoints

- **Desktop**: Full 2-column layout
- **Tablet**: Adjusted spacing and font sizes
- **Mobile**: Single column layout with optimized navigation
